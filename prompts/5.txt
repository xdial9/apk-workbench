Produce the final outputs from your memory bank. These are the artifacts the

INPUTS

DELIVERABLE 1: ai_analysis/dossier.md (human-facing; use this structure)
  # App Dossier: <package> v<version>
  1. Executive summary (5-15 lines; the answer first; severity posture)
  2. Identity & provenance (signer, lineage, obfuscation level, delivery)
  3. Attack surface (components, deep links, providers, activities)
  4. Network life (host groups, protocols, cleartext, API surface, rate
     limit posture, DNS/D1 behavior)
  5. Secrets (verified: quote file + context; hints: quote + why labeled)
  6. Behaviors & deductions (each: narrative + confidence label +
     the facts it rests on)
  7. What was verified vs what remains unknown (from cross_check +
     lead_ledger + coverage)
  8. Operator next steps (what a user of this dossier should do)
  TONE: dense, factual, no padding. Every factual claim cites a path/line
  or an entry from the machine output. Where you infer, state the chain.

DELIVERABLE 2: ai_analysis/ai_analysis.json (machine-facing; exact schema)

        "fingerprint_basis": ["surface fact id / value"] }
    ],
    "deductions": [ { "id": "D1", "narrative": "...", "confidence": "...",
                      "facts": ["A1", "E5"...], "cites": [...] } ],
    "lead_ledger": [...as stage 3 wrote...],
    "cross_check": { "disputed": [...], "missed": [...] }  // summary
  }
  RULES: every finding id referenced elsewhere must exist; every evidence
  path must be inside this folder; unknowns remain entries with label
  open_question rather than being dropped.
